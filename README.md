# SIH 2025 Team IOTA Model-1 Prototype

# Host Link (Live Demo) : https://plant-app-tchu.vercel.app/

**KHARIF** is a machine learning–powered web application that helps soil health recommendation and Fertilizer guidance.  
It combines a  Flask backend (for the ML model API) and a React frontend (for the user interface).  

 ## Features
-  Machine Learning algorithm for Fertilizer Recommendation  
-  Flask REST API serving predictions  
-  React frontend for interactive UI  
-  Deployed on Render (backend) and Vercel (frontend)  

## Tech Stack
- **Python (Flask)** – Backend & API  
- **scikit-learn and other libraries** – Machine Learning(Model Training) 
- **React** – Frontend  
- **Render / Vercel** – Deployment  


## Installation & Setup

### 1️ Backend (Flask + ML)
cd flask-api
pip install -r requirements.txt
python app.py

### 2 Frontend (React)
cd react-app
npm install
npm start

## Deployment
- **Backend**: Render (Gunicorn + Flask)  
- **Frontend**: Vercel (React build)
